# Neutral cards carry no meaning

Parallel items on a lecture slide used to be blue, green, amber, or pink. Those colors looked like a ranking, but the items were peers, such as the three Gene Ontology branches. A callout is a separate box that makes a claim: a warning, a key point, a check, or a procedure. A neutral card holds one peer and uses one muted surface. Callouts use the HEBMU color roles. The alternative was to keep a different color on each peer.
