# Diagram layout is not part of the theme look

The theme forced every diagram onto one square line path and one set of gaps. Two arrows into the same box then landed on the corners instead of the middle. Diagram look stays in the theme: purple boxes, white labels, PingFang SC at 18px and weight 700, and the gray arrows. Diagram layout uses Mermaid's own defaults. A single diagram can still choose a square line path in its own fence. The alternative was to keep one locked layout for every chart.
